Excel · CONCATENATE ＋ COUNTIF

3列に分かれた住所の重複チェック

住所が「都道府県」「市区町村」「町名・番地」のように3列に分かれている表で、同じ住所が2回以上出てくる行を見つける手順です。CONCATENATE で3列を1つの文字列につなぎ、その列を COUNTIF で数えます。

根拠について：関数の仕様は、ページ末尾の Microsoft 公式ドキュメント（2026-10-01 確認）によります。Excel で実際に動かしての確認はしていません。サンプルの住所はすべて架空です。

前提の表

1行目が見出し、2行目からデータ。A〜C列に住所が分かれて入っていて、D列とE列を作業用に使います。

A 都道府県B 市区町村C 町名・番地D つないだ住所E 件数
2A県B市桜町1-2-3A県B市桜町1-2-32
3A県B市桜町1-2-3A県B市桜町1-2-32
4A県C市4-5-6A県C市4-5-61

2行目と3行目は、区切る位置が違うだけで同じ住所です。つなげてから比べるので、どちらも件数が 2 になります。

手順

  1. D列に3列をつなげる

    D2 に次の式を入れ、最終行までコピーします。

    =CONCATENATE(A2,B2,C2)

    =A2&B2&C2 と書いても同じ結果です。

  2. E列で同じ住所の件数を数える

    E2 に次の式を入れ、最終行までコピーします。範囲は $ を付けて固定します（付けないとコピーしたときに範囲がずれます）。

    =COUNTIF($D$2:$D$1000,D2)

    1000 はデータの最終行に合わせて変えます。結果が 2 以上なら重複、1 なら重複なしです。

  3. 重複だけを表示する

    見出し行にフィルターをかけ、E列で 1 以外を選べば、重複している行だけが残ります。

用途に合わせた式

「重複」とだけ出したい
=IF(COUNTIF($D$2:$D$1000,D2)>1,"重複","")
1件目は残し、2件目以降だけに印を付けたい
=IF(COUNTIF($D$2:D2,D2)>1,"2件目以降","")
範囲の始まりだけ固定し、終わりを自分の行までにします。上から数えるので、最初に出てきた行には印が付きません。消すときは印の付いた行だけを消します。
特定の住所が表にあるか調べたい
G1〜G3 に調べたい住所を3つに分けて入れ、=COUNTIF($D$2:$D$1000,CONCATENATE(G1,G2,G3))。1 以上ならあります。
空行に印を付けたくない
=IF(D2="","",COUNTIF($D$2:$D$1000,D2)) のように、D列が空文字のときは数えないようにします。A〜C列が空の行で D列が空文字になり、この判定に引っかかるかは未確認です。

つまずきやすいところ

表記ゆれに注意

スペースの有無や、「1丁目2番3号」と「1-2-3」のような書き方の違いがあると、同じ住所でも一致しない可能性があります（未確認）。COUNTIF が全角の「１」と半角の「1」を同じとみなすかは、公式ドキュメントに記載がありません（未確認）。下の「表記をそろえてから比べる」を参照してください。

番地が日付に変わることがある

Excel は、入力した数値を日付に自動で変えることがあります（公式ドキュメントの例は「12/2」）。防ぐには、先頭に ' を付けて入力します。「1-2-3」のような番地そのものが日付に変わるかは未確認です。つないだ住所に見覚えのない数字が出ていたら、C列の値を確かめてください。

* ? ~ は特別な意味になる

COUNTIF の検索条件では、? は任意の1文字、* は任意の文字列を表します。これらの文字そのものを探すときは前に ~ を付けます。住所にこれらの半角記号が入っていると、意図しない行まで数えることがあります。

255文字を超えると正しく数えない

COUNTIF は 255 文字より長い文字列の照合で、正しくない結果を返します。つないだ住所がこの長さを超えることはまれですが、備考などまでつなげる場合は注意します。

CONCATENATE は旧関数の扱い

Excel 2016、Excel Mobile、Excel for the web では、CONCATENATE は CONCAT に置き換えられました。CONCATENATE も互換性のために引き続き使えますが、Microsoft は CONCAT の使用を検討するよう勧めています。

表記をそろえてから比べる

この節の式は Excel で動作確認していません：使う前に、数行で結果を確かめてください。

全角・半角とスペースのゆれをまとめて吸収したい場合の式の例です。D列を次の式にします。

=SUBSTITUTE(SUBSTITUTE(ASC(CONCATENATE(A2,B2,C2))," ",""),"　","")

ASC
日本語などの2バイト文字の言語で、全角（2バイト）の文字を半角（1バイト）に変える関数です。記号の「－」が変換の対象になるかは未確認です。
SUBSTITUTE
文字列の中の指定した文字を置き換えます。ここでは半角スペースと全角スペースを空文字 "" に置き換えて、消すことを狙っています（空文字への置き換えは公式ドキュメントに例がなく、未確認）。

この式でスペース以外に置き換えているものはないので、「丁目・番・号」と「-」の違いのような書き方のゆれは残ります。数が少なければ、E列が 1 の行を目で見直すのが確実です。
