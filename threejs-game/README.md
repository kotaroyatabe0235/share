# threejs-game

見本のコードを自分の手で打ちながら学ぶ、写経の練習ページです。JavaScript の基本から始めて、Three.js での3Dゲームづくりまで進む予定です（いまは第3回まで）。サーバー側のプログラムは使わず、ブラウザの中だけで動きます。ただし第3回は three.js をネット（jsDelivr）から読みこむので、ネットにつながっている必要があります。

## 使い方

- 説明と見本、打つ欄があります。広い画面では左右に、狭い画面では上下に並びます。見本の色のついた行が、前の歩から増えた行です（1歩目は全部の行に色がつきます）。前の歩から消えた行は、見本の下に「この歩で消す行」として出ます。
- 打った行が見本と合っているかは、その場で表示されます。行の前後の空白と、空の行は比べません。
- 「実行」で、打ったコードの結果が下に出ます。
- 進み具合と打ったコードは、そのブラウザの中にだけ保存されます。保存が使えない設定のブラウザでは、保存されません。
- 主にタッチで操作する端末（スマホなど）では、打つ欄の上に記号を入れるボタンが出ます。

## ファイル

- `index.html`・`style.css`・`app.js`：ページの本体
- `favicon.svg`：ブラウザのタブに出るアイコン
- `lessons/<回>.js`：回ごとの中身（説明・見本・気をつけるところ・変えてみよう・出典）

## 回を足すとき

1. `lessons/` に回のファイルを置く（`01-js.js` と同じ形）。
2. `app.js` の `LESSON_IDS` に1行足す。

## 回の一覧

- 第1回 Java と違う JavaScript（型を書かない変数、比べ方、数、関数と配列とオブジェクト）
- 第2回 ページを JavaScript で動かす（要素をつかむ、書き換える、押されたら動く）
- 第3回 Three.js で箱を1つ出す（部品の読みこみ、空間・カメラ・描く係、形と材質、光）
